# Robot Hand Control for Pick and Place

## Descripción

Este repositorio contiene el software desarrollado para el control de la mano robótica Dex3-1 de la humanoide Aura, incluyendo movimientos básicos y secuencias de agarre y manipulación de objetos.

## Contenido

- `src/`: Movimientos básicos y funciones de control.
- `pick_and_place_movements/`: Secuencias de agarre y pick-and-place.
